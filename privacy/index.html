Privacy Policy

Last updated: September 3, 2026

This Privacy Policy explains how Peer Feedback Organizer accesses, uses, stores, and shares information when you use the tool within Google Sheets.

Information accessed

Peer Feedback Organizer requests access to the Google spreadsheet in which the tool is being used. This access allows the tool to read and modify spreadsheet data needed to provide its features, including peer-feedback notes, roster information stored in the workbook, priority values, status values, note types, and related organizational data.

How information is used

Spreadsheet data is used only to provide the functionality of Peer Feedback Organizer. This includes importing feedback, organizing feedback into spreadsheet columns, updating status and priority fields, and filtering feedback.

Data storage

Peer Feedback Organizer does not operate an external database or server for storing the contents of your spreadsheet. Data processed by the tool remains in the Google Sheet and within Google's Apps Script environment as necessary to run the requested functions.

Data sharing

Peer Feedback Organizer does not sell Google user data and does not share Google user data with third parties for advertising, marketing, or unrelated purposes.

Google API Services

Peer Feedback Organizer's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Security

The tool is designed to request only the Google account permissions necessary to perform its spreadsheet functions. Users should follow normal Google account and spreadsheet-sharing security practices.

Changes to this policy

This Privacy Policy may be updated if the functionality or data practices of Peer Feedback Organizer change. The current version will remain available on this page.
